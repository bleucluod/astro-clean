# Notes for Next Steps

## Current status

Astro Clean has a stable frontend MVP.

Confirmed:

- lint passes
- production build passes
- production preview works
- manual route testing passed
- local Git checkpoints exist
- MVP release tag exists: v0.1.0-mvp

## Current MVP focus

The product is intentionally frontend-only for now.

We are not adding:

- backend
- database
- authentication
- Docker
- Prisma
- PostgreSQL
- Redis
- AI integration
- payment
- programmatic SEO
