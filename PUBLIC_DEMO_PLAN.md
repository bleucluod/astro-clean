# Public Demo Plan

## Purpose

The first public demo of Astro Clean should show the product experience clearly without pretending the product is already a full backend-powered astrology platform.

## Main demo story

A first-time user should understand this flow:

1. Open Home
2. Create a mock chart
3. Land on the saved report detail page
4. Read the symbolic report
5. Add a personal note
6. Mark important reports as favorites
7. Search reports
8. View the Dashboard
9. Understand that data is stored locally
10. Export or reset local data from Admin

## Public demo positioning

Astro Clean is currently:

- a Persian symbolic astrology MVP
- a frontend-first product demo
- localStorage-based
- privacy-transparent
- not a scientific prediction tool
- not medical, legal, or financial advice

## What to say if someone asks whether reports are real

Current answer:

The current demo uses a mock astrology engine to validate the product experience, Persian UX, report workflow, notes, favorites, backup, and dashboard. Real astrology calculations are planned as a separate engine layer.

## What to say if someone asks about SEO

Current answer:

Public SEO pages are planned for future public accounts and public reports, but they need explicit user consent, privacy controls, canonical URLs, noindex/index rules, and high-quality keyword generation. They are not active in this release.

## What to measure after public demo

Qualitative feedback:

- Does the user understand what the product does?
- Does the user trust the local data explanation?
- Does the report flow feel satisfying?
- Does the user want real chart calculations?
- Would the user pay for a real personalized report?
- Would the user create a public profile if privacy controls are clear?

Possible early conversion goals:

- waitlist signup
- manual report request
- early access request
- feedback form
- social follow
