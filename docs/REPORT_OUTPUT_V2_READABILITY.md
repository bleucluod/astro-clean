# Halleus Report Output V2 Readability

This milestone improves the visible reading experience for sectioned reports.

## What changed

- Added report V2 metrics.
- Added section count, word count, reading time, and quality score.
- Added a section selector so users can focus on one section.
- Kept copy and TXT download actions.

## Why this matters

The report detail page now feels more like a readable product surface, not just a raw data dump.
