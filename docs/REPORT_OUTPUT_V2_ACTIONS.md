# Halleus Report Output V2 Actions

This milestone makes the sectioned report output more useful for real users.

## What changed

- Report Output V2 now has a TXT download action.
- Report Output V2 now has a copy-to-clipboard action.
- Older reports still get enhanced at render time.
- The UI gives a clear fallback when clipboard access fails.

## Why this matters

A report is only useful if the user can keep it, copy it, or share it.

This is a visible product improvement, not just another foundation layer.
