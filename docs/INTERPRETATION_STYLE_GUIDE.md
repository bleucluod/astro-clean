# Halleus Interpretation Style Guide

## Voice

Persian-first, warm, clear, and non-deterministic.

## Good language

- "می‌تواند نشان بدهد"
- "ممکن است برای تأمل مفید باشد"
- "از نگاه نمادین"
- "این بخش را به عنوان دعوت به فکر کردن ببین"

## Avoid

- "قطعاً"
- "حتماً"
- "سرنوشت تو این است"
- "باید این تصمیم را بگیری"
- medical, legal, or financial instructions

## Structure

Every full report should include:

1. Overview
2. Identity
3. Emotional pattern
4. Relationships
5. Career and growth
6. Reflection prompts
7. Disclaimer
