# Halleus Chart Engine Foundation

This milestone prepares the real chart engine path without replacing current mock reports yet.

## What was added

- Chart engine types.
- Chart engine driver contract.
- Mock preview engine.
- Engine factory.
- Engine readiness report.
- Deterministic fixture inputs.
- Engine readiness page.
- Engine foundation checker.

## Current state

The active report generation flow still uses the existing preview/mock report system.

This phase creates the future replacement path without breaking the existing user flow.

## Why this matters

The real astrology engine is a high-risk product area.

It should be introduced with:

1. input contract
2. deterministic fixtures
3. placement schema
4. calculation strategy
5. interpretation modules
6. quality review
7. UI migration

Do not mix calculation correctness and UI rewriting in one step.
