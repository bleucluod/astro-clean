# Halleus Finglish Copy Workflow

## Goal

Use controlled Finglish for draft speed, then convert known phrases into Persian before writing user-facing UI.

## Rule

Finglish is a drafting format, not the final UI language.

## Current examples

- gozaresh -> گزارش
- bakhsh -> بخش
- namadin -> نمادین
- taamol -> تأمل
- tavallod -> تولد
- chart -> چارت
- engine -> موتور

## Future path

The phrase map can grow with product copy, report sections, and action labels.
