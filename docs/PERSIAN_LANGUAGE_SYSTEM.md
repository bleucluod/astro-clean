# Halleus Persian Language System

This milestone creates the first centralized language layer for Halleus.

## What was added

- Language types.
- Controlled Finglish phrase map.
- Finglish-to-Persian converter foundation.
- Persian product copy registry.
- Language readiness report.
- Public language page.
- Product surface language link.
- Language system checker.

## Why this matters

Persian text should not be patched randomly across the app.

A central language layer reduces UTF-8 risk, improves consistency, and lets us draft future copy in controlled Finglish before converting it to Persian.
