# Halleus Report Output V2 UX Polish

This milestone makes Report Output V2 visible for both new and existing reports.

## What changed

- ReportV2Sections now safely enhances any report object before rendering.
- Existing legacy preview reports can show the sectioned V2 preview without requiring regeneration.
- Added plain text export helper for sectioned V2 reports.
- Added a dedicated checker for the V2 UX layer.

## Why this matters

The visible report experience should improve immediately.

Even older local-preview reports now have a sectioned display path.
