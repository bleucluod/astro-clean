# Halleus Environment Configuration

This document lists intended environment variables.

They are not all required yet.

## Public app

```env
NEXT_PUBLIC_HALLEUS_SITE_URL=https://halleus.ir
NEXT_PUBLIC_HALLEUS_BRAND_NAME=Halleus
```

## Database later

```env
DATABASE_URL=
```

## Auth later

```env
AUTH_SECRET=
AUTH_GOOGLE_ID=
AUTH_GOOGLE_SECRET=
```

## Payment later

```env
PAYMENT_PROVIDER=
PAYMENT_SECRET_KEY=
PAYMENT_WEBHOOK_SECRET=
```

## Rule

Do not add real secrets to Git.

Use Render environment variables or the selected hosting provider secret manager.
