# چک‌لیست پیاده‌سازی بسته محتوا

## ۱. قرارداد Index و Robots

- [ ] Homepage، `/chart`، `/compare`، `/sky`، `/wiki`، `/product`، `/pricing`، `/order` و `/privacy` براساس تصمیم فعلی `index, follow` هستند.
- [ ] خود `/compare` Landing Page عمومی، دارای canonical برابر `/compare` و عضو Sitemap است.
- [ ] `/compare/[comparisonId]` و همه نتیجه‌های شخصی Compare: `noindex, nofollow, noarchive, nosnippet`.
- [ ] نتیجه‌های Compare Public Share ندارند و از صفحات عمومی لینک Crawlable نمی‌گیرند.
- [ ] Layout مشترک Compare نباید به اشتباه `noindex` را به Landing Page عمومی تحمیل کند.
- [ ] هر صفحه canonical خود را دارد و Duplicate canonical ایجاد نشده است.

- [ ] Mobile محتوای اصلی، لینک‌ها یا FAQ لازم را حذف نمی‌کند.
