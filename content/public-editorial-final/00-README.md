## قرارداد حیاتی Compare

- خود `/compare` یک Landing Page عمومی است و باید `index, follow`، دارای canonical برابر `/compare` و عضو Sitemap باشد.
- فقط نتیجه‌های شخصی مانند `/compare/[comparisonId]` خصوصی‌اند و باید `noindex, nofollow, noarchive, nosnippet` باقی بمانند.
- هیچ Public Share یا صفحه قابل ایندکس برای نتیجه تحلیل رابطه ساخته نمی‌شود.

## قرارداد Publication و Privacy

- گزارش مهمان و حساب رایگان به‌صورت پیش‌فرض عمومی و قابل ایندکس هستند.
- گزارش Premium به‌صورت پیش‌فرض خصوصی و `noindex` است و فقط با انتخاب صریح صاحب گزارش عمومی می‌شود.
- نمایش نام یا هویت، رضایتی جدا از انتشار گزارش است.
- تحلیل رابطه همیشه خصوصی و `noindex` می‌ماند.
- ثبت سفارش، خرید یا پرداخت به‌معنی رضایت انتشار نیست.
- داده تولد، نام، ایمیل، متن گزارش و متن تحلیل رابطه نباید به Analytics ارسال شوند.

## روش استفاده

1. ابتدا Keyword Map و Internal Link Map را با سورس واقعی تطبیق بده.
2. متن هر صفحه را داخل Sectionها و Componentهای واقعی همان Route ادغام کن؛ متن را به‌صورت یک دیوار طولانی پایین صفحه قرار نده.
3. داده‌های Dynamic و Engine-driven را از Source of Truth موجود بگیر و Hardcode نکن.
4. Placeholderهای تجاری Pricing تا زمان تصمیم واقعی محصول نباید در UI Production دیده شوند.
5. Robots، Canonical، Sitemap و Privacy را طبق Checklist کنترل کن.
6. متن ردشده یا نسخه قبلی این بسته نباید وارد Candidate نهایی شود.
